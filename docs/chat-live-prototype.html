ChatView 交互原型 v4

Codex 风格ToolView 聚合错误态

v4 变更：① 工具行文案固定为动作短语（"写入 xxx"），状态由图标表达（spinner / ✓ / ✕），不再用"已完成"前缀；② 失败工具 = ✕ 红色 + 错误摘要，区段头部按最差状态显示；③ shimmer 状态条回归（composer 上方，存活指示：动画在跑 = 没卡）；④ 完成行带耗时。

状态设计

  • 行状态：进行中 spinner / 成功 ✓ / 失败 ✕（红）；文案不随状态变化
  • 区段头部：running > error > done 优先级—— ⏳ 正在运行 2 个工具… / ⚠ 工具调用 (3) · 1 个异常 / ✓ 工具调用 (4)
  • 状态条：shimmer 流动 + spinner + "正在运行 2 个工具…"；动画持续 = 后端存活（API 卡了用户可感知）
