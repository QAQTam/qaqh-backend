## 3. 关键决策（评审/实现期新增，均已写进契约）

1. **类型归属（契约 §3.1/D1）**：SDK 内部类型在 `qaqh-workspace::tool_api`，wire 在 `qaqh-domain`，映射唯一收敛在 `qaqh-runtime::timeline::wire_display`；禁止 domain 反向依赖。
2. **投影声明方式**：本期用 `ToolManager::register_display`（名字 → fn），**没有**给 `ToolHandler` 加字段（避免 20+ 字面量 churn）；`TypedTool` 落地后收敛为 `TypedTool::display(&args)`（H13 不变：timeline/前端不得自行解析工具输出）。
3. **metrics 落点**：进 `ToolResult.metrics`（base spec §11 本就要求 metrics 入 ToolResult 扩展区），随 message store 持久化 → `ToolResultDef.metrics` → rebuild 可还原；`elapsed_ms: Option`，None = 未接线，wire `display.metrics` 为 `None`。
4. **归一化责任（§5.2 v1.1 修订）**：终态 `body.output` 后端归一化（ANSI 现状 + `\r` 覆盖）；**流式 progress 原样透传**（已发字节无法撤回），`\r`/ANSI 覆盖语义由 client 在累积缓冲上渲染（TUI `apply_bash_progress` 保留）。前端如按旧稿理解请以此为准。
5. **兼容策略（H7/H16）**：新字段全 `serde(default)` + skip；`Unknown` 变体兜底；`display` 缺失 = client 完整回退旧字段，不得部分解析。

## 4. wire 速查（前端现在能用）

- `TimelineTool.display: Option<TimelineToolDisplay>`（快照 + SSE 同源；缺失/`Unknown` → 回退旧字段）。
- `display.summary`（H1：永不为 JSON）、`display.header`（`shell{command}` / `path{path,op}` / `query{query,scope}` / `other`）、`display.body`（`shell{output,exit_code,truncated}` / `text` / `diff` / `subagent{name,seed}`）、`display.metrics`（`elapsed_ms/output_bytes/retry_count/effective_tool_name/user_initiated`）。
- `TimelineTool.progress_stream`（`"stdout"|"stderr"`）、`progress_bytes_total`（累计观测字节，含丢弃/裁剪）。
- 已产出投影：exec、read、write、edit、apply_patch、glob、delete、copy_range、grep、web_fetch、todo_write/todo_update/todo_list、process、journal、ask、skills、spawn_subagent。其余工具 `display = None` → 前端按旧逻辑渲染（H16 回退 gate）。

## 7. 风险与注意事项

1. `ToolResult` 新增 `metrics` 字段：所有测试已验证兼容；今后若有测试对 `ToolResult` 做**整体相等**断言，须记得 metrics 参与比较（默认空对象 = 与旧构造一致）。
2. `ExecProgressSender::try_send` 现在维护 emitted/dropped 双计数（fetch_add/fetch_sub）；若未来并发化，需保持「总量不变」的不变量（见 `exec/tests.rs::bounded_progress_queue_drops_updates_without_blocking_pipe_readers`）。
3. `progress_bytes_total` 是**累计观测**口径（含丢弃/裁剪），与 `display.metrics.output_bytes`（最终展示文本字节）语义不同，勿混用（H12）。
4. TUI 仓 `src/app/render/` 与多个 src 文件是前端团队在途改动，本轮只提交了两份 docs（`32f8478`）；请勿在未沟通时合并/回退他们的工作区。
