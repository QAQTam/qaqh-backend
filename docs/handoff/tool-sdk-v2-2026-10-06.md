## 风险提示（新增/更新）

- **`deny_unknown_fields` 与 required 收紧**：生成 schema 的 required 集合与手写版
  不同（serde(default) 字段不再 required），行为由 run() 内校验兜底——v2 已知行为，
  exec.shell/command、web_fetch.url、read 均已按此修测试。新增 Args 字段时记得：
  必填语义要么不放 serde(default)，要么 run() 校验兜底。
- **生成 schema 的 enum/null 形态**：Option<enum> 生成为扁平 enum + null 成员
  （todo_list.status 实测）；断言 schema 结构时先 probe 再写，勿凭 anyOf 猜。
- **旧会话重建**：skills 三新工具名与历史 "skills" 记录并存；typed payload 反序列化
  只对 todo 三件套生效（display.rs:112），"skills" 旧记录靠保留的 register_display
  兜底。
- **git CLI 依赖**：code_delta 的 git_file_meta 现依赖 PATH 上有 git（原 libgit2 无此
  依赖）。探测失败静默回退 None（行为同旧 open 失败），但纯净环境（无 git）下
  files_created 修正会缺席——评估可接受（daemon 目标环境本就带 git）。
- **cargo 并发假红**：见验证状态。CI/本地脚本若并行跑 cargo，失败先隔离重跑。
