  `pub(crate) use` 导出。

  工具侧调用已全部删除。

  注明 requests 优先。

  validate 退役（`qaqh_skills::validate_file` 保留宿主侧）；`register_display("skills",...)`

- 20 个内置工具全部迁移完（我 + 2 个并行 agent）：descriptor→meta、手写 schema 全删、

- `tool_capabilities.rs` TABLE：20→22 条（skills → skill_activate=SESSION_MUTATING,
  skill_list/skill_resource=READ_ONLY）。
- `registration.rs` 词汇测试 22 工具；`execution.rs` skill 测试、`spawn.rs` subagent 默认
