## 4. 尚未完成的工作

### 4.1 必须从实现开始

当前 `crates/**` 尚未落地 v2 canonical types；不要因为 spec 已 approved 就把 I1-I15 写成已完成。建议实现顺序：

1. `FactPayload/SessionFact/ReliableCursor/ProjectionSlot/ProjectionPayload` Rust 类型与 serde/golden fixture。
2. canonical `events.jsonl`、单 writer lock、`writer-fence.json`、append/fsync 顺序与 torn-tail 恢复。
3. projection rebuild、复合 cursor、replay/dedupe、snapshot/replay-window expiry。
4. `ToolIntent/ToolFinished` durable ledger、policy lifecycle、recovery batch/plan_hash。
5. `ContentClockRecord`、Content GC、legal hold/offload、quota 与 IO failpoint。
6. legacy mapping、writer fencing、cutover/rollback CLI 与迁移 E2E。
7. backend rev 固定后再做 TUI reducer/wire-boundary 跨仓验收。

- 从最新 `origin/betav2 @ 5e0a9a9` 创建独立 issue/worktree/分支。
