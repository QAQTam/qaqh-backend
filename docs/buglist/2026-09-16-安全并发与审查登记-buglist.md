## 快速迭代专项

- `crates/qaqh-daemon/src/axum_server.rs:1` 注释 P1.5 「默认 HTTP 栈」与 `crates/qaqh-daemon/src/server.rs:21` 「临时跨端模式，不做任何安全加固」**互相矛盾**；建议以 axum_server 为唯一权威、server.rs 改正后收口。
- `crates/qaqh-session/src/manager.rs:1168-1181` `generate_unique_seed` random fallback 仅允许子代理/临时使用 — 但 `agent/state/lifecycle.rs:248-260` 生产 fallback 也走了 generate_unique_seed 路径，会在 seed 冲突时随机化 (**不推荐 in production path**)。请用 `try_generate_unique_seed` 单一事实源。
- `crates/qaqh-session/src/manager.rs:1145-1152` `seed_hasher` 使用 `DefaultHasher` （SipHash, temporal seed aging);应改为 `sha2::SHA256` 或 `rand 0.10 chacha20`(getrandom) 以避免原次 striping / DoS.
- `crates/qaqh-config/src/registry.rs:177-186` 文本级提取 `[providers]` 顶层 header ;嵌套表中含 `[sub]` 会被截段, 导致 provider 空表静默 成 failed load; 应改 `toml::Value` AST。
- `crates/qaqh-runtime/src/service.rs` `handle` 中 seed 校验缺 8-hex pattern；允许 `seed=""`/seed без hex 混入fs 路径。 补 shared helper `validate_seed_hex()`。
- `crates/qaqh-runtime/src/agent/state/agent.rs:1145-1152` `init_tools` 使用 `DefaultHasher`；`agent/token_calibration.rs:165` 也共 DefaultHasher 应换 `sha256`,测试注入 per-fingerprint fingerprint 不可偏移。
- `tools/cnb-mcp-enhance/server.mjs:476-500` `deviceAuth` 未给时间 connector;`sleep()` no AbortSignal.timeout ⇒ user 可能永久挂起（列表中已提 P1-2）, compound at `withAuth` abort。
