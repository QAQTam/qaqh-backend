# docs/archive — 历史归档区

> **本目录只存历史。**
>
> 从 2026-09-25 起，`docs/` 的权威文档只在 `docs/current/`。本目录及其
> `pre-reset/` 子树中的任何内容都不再作为当前实现、接口或排期依据。

## 目录

```text
docs/archive/
├── README.md
└── 2026-09/
    ├── buglist/   早期已闭环缺陷记录
    ├── handoff/   早期交接记录
    ├── report/    早期调查报告
    └── pre-reset/ 2026-09-25 文档重置前的全量文档快照
```

## 使用规则

1. 查当前行为：只读 `docs/current/`。
2. 查历史原因：读 `docs/archive/`，但必须先确认代码/测试现状。
3. 不修改归档内容；需要新结论时在 `docs/current/` 新建文档。
4. 归档中的相对链接按归档时坐标保留，不保证继续跟随新目录维护。
