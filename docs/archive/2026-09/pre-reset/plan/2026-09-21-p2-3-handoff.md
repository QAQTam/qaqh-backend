## 3. 当前架构事实

P2-3 解决的是取消语义收敛，不代表 `SessionActor` 已接管整个 runtime：

- `SessionActor` 仍是 runtime adapter 参与生命周期镜像，`run_lap` 仍是实际执行器。
- 输入、取消、审批、订阅尚未全部成为唯一 mailbox ingress。
- workspace/session cancel bridge 仍存在，不能提前删除。
- compaction/title/liveness/session lifecycle 仍在 loop 路径内。
- `SubagentSupervisor`、两阶段 spawn 恢复、root `QuotaLedger` 尚未实现。

不要把“P2-3 完成”描述成“SessionActor 已是 runtime 唯一 owner”。

## 5. 开发与合并流程

1. 先创建 issue。
2. 从 `betav2` 创建独立 branch/worktree：

   ```bash
   git worktree add -b <type>/<issue>-<slug> \
     /home/qaqtamsy/Projects/qaqh-worktrees/<issue>-<slug> betav2
   ```

3. 只做一个可验收切片；先保持旧行为 1:1，再做所有权转移。
4. 跑定向测试、`cargo test --workspace`、`cargo clippy --workspace --all-targets -- -D warnings`。
5. commit/push 后创建 PR，base 固定为 `betav2`。
6. 检查 `cnb pulls get-pull` 的 `mergeable_state`；NPC 自动审查失败不作为阻塞。
7. `cnb pulls merge-pull` 合并。
8. 手动关闭实现 issue。
9. 主工作区 `git fetch origin && git merge --ff-only origin/betav2`。
10. 合并证据单独 issue/PR 回写计划文档。
