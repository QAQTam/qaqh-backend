# QAQ-Harness Backend 2.0.0-alpha3

> 日期：2026-09-26
> 代码基线：`9d318b6`（TUI/WinUI client 契约同步）+ alpha3 version bump
> 状态：released checkpoint

## 1. 一句话

Alpha3 完成 Subagent V2 的后端与消费侧契约闭环：agent tree、mailbox、
residency、Team projection、task board、message board、steer/interject 均可从
canonical facts 重建并供 TUI / WinUI 消费。

## 2. 主要交付

### Agent tree / mailbox / lifecycle

- `AgentId = SessionId`，`AgentPath` 是稳定树地址。
- durable parent-child graph 与 `SubagentSpawned/Finished` canonical producer。
- canonical mailbox、`queue` / `trigger` / `interrupt` delivery。
- unload/reload residency、parent ownership gate、depth 与消息配额。
- `close_agent` 退出 V2 工具面；`interrupt_agent` 保留逻辑身份。

### Team projection

- `TeamSnapshot` / `TeamDelta` 覆盖 roster、status、residency、inbox。
- runtime residency 是 daemon-local overlay，重启后回到 `unloaded`。
- `qaqh-client` 从根导出 typed Team projection 与 `Client::team_v2(seed)`。

### Task board

- 独立 Team canonical aggregate，支持 claim epoch、dependency、artifact、
  acceptance、complete/close/cancel。
- runtime tools：`task_create` / `task_claim` / `task_update` / `task_close` /
  `task_list`。
- `/team` 返回 task snapshot；`TeamDelta::TaskChanged` 走 per-seed 单流。

### Message board

- 独立 `BoardFact` / `BoardStore`，支持 channel / thread / post / subscription。
- runtime tools：`board_channel_create` / `board_thread_create` / `board_post` /
  `board_subscribe` / `board_list`。
- post 先 durable；notification 只对 running + loaded subscriber 做
  queue-only best-effort，missed notification 不保证补发。
- `task_id` 与 task board 同 root tree 关联。

### Steer / Interject

- 新增 `steer` / `interject` delivery 与 canonical `InputPurpose`。
- safe point = 工具批完成、下一次模型请求之前。
- 同 lap 顺序：`interject -> steer -> queue`。
- 单 safe point 上限：8 steer / 4 interject；溢出保留到下一 safe point。
- `interrupt` 仍是唯一取消当前 turn 的 delivery。
- 新增 `steer_agent` / `interject_agent`；child 不得向 root steer/interject。

### Content / persistence

- 大正文 `content_ref`、durable content store、TTL/pin/quota 已落地。
- `InputAccepted` / `InterAgentCommunication` 大正文不再跳过 canonical fact。
- pending interaction 正文可从 canonical content ref 重建。

## 3. Wire / migration notes

- `GET /ringing/v2/sessions/{seed}/team` 响应包含 `team`、`tasks`、`board`。
- per-seed 单流新增 `TeamDelta::TaskChanged` 与 `TeamDelta::BoardChanged`。
- TUI / WinUI 必须：
  - 先拉 team snapshot，再应用 ephemeral delta；
  - 以 `AgentPath` 为 roster 主键；
  - 区分 `status` 与 `residency`，`unloaded != completed != closed`；
  - 不再从 `spawn_subagent` 工具卡 JSON 推导身份。
- 版本号从 `2.0.0-alpha2` 升到 `2.0.0-alpha3`。
- Beta 身份迁移（wire `seed` -> `session_id`、删除 legacy resolver）仍属 beta
  硬门禁，不在 alpha3 完成范围内。
