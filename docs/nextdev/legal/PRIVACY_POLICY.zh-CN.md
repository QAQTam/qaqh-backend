# DeepX 隐私政策

文档版本：2026-07-27.1

适用软件版本：1.0.0-beta.1

更新日期：2026 年 7 月 27 日

生效日期：2026 年 7 月 27 日

DeepX 是本地优先的 AI 辅助软件。本政策说明 DeepX 处理哪些数据、为什么处理、数据保存在哪里，以及您如何管理这些数据。

## 隐私摘要

- DeepX 当前不提供统一云账号，也未发现内置广告、行为分析或独立遥测上报。
- 会话、配置、日志和工具审计默认保存在您的设备上。
- 只有当您调用模型、搜索、网页访问或更新功能时，相关数据才会发送给您选择或触发的第三方服务。
- API Key 保存在本地配置中，仅用于向您选择的模型服务商鉴权。DeepX 不应把 API Key 写入日志、命令行、会话或工具审计。
- 默认卸载保留用户数据；选择“同时删除用户数据”时，仅删除界面明确显示并通过安全验证的全局 DeepX 数据目录。工作区内的 `.deepx` 数据需由您另行处理。

## 二、我们处理的数据

### 1. 配置和凭据

为了连接您选择的模型服务，DeepX 在本地处理：

- 模型服务商、接口地址、模型名称和生成参数；
- API Key 及子代理相关配置；
- 语言、主题、权限等级和其他应用设置。

Windows 下主要保存在 `%USERPROFILE%\.deepx\config.toml`，启用配置数据库镜像时还会写入同目录的 `config.db`。当前测试版的 API Key 以可读取形式保存在本地配置中；正式版计划使用 Windows DPAPI 或等效系统能力保护密钥。Base64 仅作为密文编码，不作为安全措施。

当您在安装器中同意本政策和用户协议时，DeepX 会在全局数据目录写入 `legal-consent.json`，其中包含同意状态、文档版本、软件版本、同意时间、两份文档的 SHA-256 和来源。该记录不包含姓名、账号或 API Key，用于避免重复提示，并判断文档变化后是否需要重新确认。

### 2. 会话与工作区数据

为了恢复会话和执行任务，DeepX 可以在本地处理：

- 您的提示词、模型回复、推理或状态事件；
- 工具调用、工具结果和相关文件路径；
- 会话名称、时间、模型、工作区位置和计划；
- 您授权读取或写入的文件内容；
- 工作区内由 DeepX 创建的 `.deepx` 数据。

全局会话通常保存在 `%USERPROFILE%\.deepx\sessions`。启用数据库功能时，部分数据可能存在本地 SQLite 镜像。

### 3. 日志与工具审计

为了诊断故障和审查工具执行，DeepX 可以在本地保存：

- `agent.log`：运行状态、警告和错误；
- `audit.csv`：工具名称、动作、参数摘要或哈希、结果、耗时和涉及的文件路径。

日志不应包含 API Key、Authorization 头或完整配置请求。文件路径和错误信息仍可能反映您的项目结构，请在分享日志前检查和脱敏。

### 4. 前端本地状态

Electron 前端可以通过 Chromium 用户数据目录保存：

- 语言和主题；
- 最近工作区路径；
- 当前或最近会话标识；
- 窗口和应用偏好、缓存。

这些数据通常位于 Windows 当前用户的 AppData 中，由 Electron 根据应用名称管理。

### 5. 安装和更新数据

安装器和更新器可以处理：

- 安装目录、组件版本、安装标识和组件清单；
- 运行中的 DeepX 进程信息；
- Windows 快捷方式和卸载注册信息；
- 本地更新源，或 GitHub Release 更新资源的地址和响应。

## 三、数据如何对外发送

### 1. 模型服务商

当您发起模型请求时，DeepX 会向您选择的服务商发送完成请求所需的数据，可能包括：

- 会话消息和上下文；
- 系统指令和工具定义；
- 工具调用结果；
- 您明确加入上下文的文件内容；
- 模型参数和 API Key。

可能支持的服务商包括 DeepSeek、OpenAI、阿里云百炼、智谱、Moonshot/Kimi、MiniMax、火山引擎及其他兼容接口。实际接收方由您的配置决定。相关服务商按照其自身隐私政策和服务条款处理数据。

### 2. 搜索和网页访问

当您使用搜索功能时，搜索词可能发送至 Bing RSS 搜索服务。当您使用网页访问工具时，请求地址、网络标识和必要请求信息会发送至对应网站。

### 3. 更新服务

当您检查或下载在线更新时，DeepX 可能访问 GitHub Release 或未来配置的更新服务。服务提供方通常能够获得 IP 地址、请求时间、User-Agent 和下载资源等常规网络日志。

### 4. 不进行的处理

除非后续版本另行显著告知并依法取得必要授权，DeepX 不会为了广告画像出售个人信息，也不会把本地会话主动上传到独立的 DeepX 分析服务器。

## 四、处理目的和法律依据

我们仅在下列目的所必要的范围内处理数据：

- 提供本地会话、模型调用、工具执行和恢复功能；
- 保存您的配置和偏好；
- 保障进程通信、权限控制、更新和卸载安全；
- 诊断故障、审查工具操作和改进稳定性；
- 履行适用法律规定的义务。

涉及由您主动选择的可选联网功能时，我们依据您的明确操作或同意处理相应数据。您可以通过不配置服务、停用功能、删除会话或卸载软件停止后续处理。

## 五、保存期限

本地配置、会话和工作区数据由您控制，通常保存至您删除相应会话、文件或用户数据。

当前测试版日志和审计文件尚未设置自动保留期限，会持续保存至您手动删除或选择删除用户数据。正式公开发行前，我们计划提供日志轮转和清晰的保留策略。

第三方服务的保存期限由对应服务商决定，请查阅其隐私政策。

## 六、数据安全

DeepX 采取或计划采取以下措施：

- 本地 daemon 使用随机控制令牌进行进程间认证；
- 前端启用上下文隔离、沙箱并关闭 Node.js 集成；
- 工具权限分级和执行审计；
- 更新包和安装状态校验；
- 卸载删除前执行路径、所有者、标记、重解析点和删除预算检查；
- 日志和界面返回中的凭据脱敏。

任何系统都无法保证绝对安全。如果您发现漏洞或怀疑 API Key 泄露，请停止相关服务、轮换密钥并联系我们。

## 七、您的权利和控制方式

您可以：

- 在设置中查看、修改或替换模型配置；
- 查看和删除会话；
- 删除本地日志和审计文件；
- 卸载时选择是否删除明确显示的全局用户数据目录；
- 不使用模型、搜索、网页访问或在线更新功能；
- 通过本政策所列渠道提出查阅、更正、复制、删除、限制处理或解释请求。

为防止误删，卸载器不会自动遍历并删除所有工作区中的 `.deepx` 目录。您可以在确认具体工作区后自行删除。

## 八、跨境处理

如果您配置位于境外的模型服务、网站或更新服务，相关请求可能在境外处理。接收方、数据类型和保存方式取决于您的选择及对应第三方服务。

在正式提供由我们决定的跨境数据处理功能前，我们将根据适用法律完成必要评估、告知和同意流程。

如果我们发现未经适当同意处理了未成年人的个人信息，将采取措施删除或停止处理。

我们可能因功能、数据处理或法律变化更新本政策。发生重大变化时，将通过安装器、应用界面或项目发布页面进行显著提示，并在依法需要时重新取得同意。
